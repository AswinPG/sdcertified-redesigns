# SD Certified — 40 Design Concepts (Rounds 2 + 3)

Client presentation site for the **SD Certified** marketplace redesign.
*SD Certified is an offering of [Suresh Drives](https://sureshdrives.com) — India's first professional on-site car inspection company (Kozhikode, Kerala).*

The front page lists all 40 concepts; each card opens a complete **7-page prototype**:

1. `index.html` — welcome / hero
2. `browse.html` — filters + 16-car listings
3. `vehicle.html` — car sheet with 300-point report (Bentley Flying Spur, Lot SD-2481)
4. `sell.html` — seller flow (wizard / form / quote / checklist variants)
5. `certification.html` — Platinum / Gold / Silver grades
6. `pricing.html` — ₹9,999 flat package + SD Prime Assist
7. `contact.html` — contact cards, team, testimonials
